# 방향 A — AI 중심 국내 법 검토 (2026-10-24 결정, 11/25 갱신)

## 한 문장

국내 법령에서 코드에 흔적이 남는 의무를 지도로 만들고, AI 가 폴더의 코드를 읽어 그 서비스에 걸릴 수 있는 의무마다
근거(파일:줄)를 내되 **코드 줄을 인용한 판단만** 받아들이는 로컬 CLI.

과제명 "AI 기반 로컬 코드 보안·이슈 점검 CLI 도구"는 그대로다. 점검하는 이슈가 보안·품질 8유형에서 국내 법·정책
의무로 바뀌었고, 판정의 중심이 규칙에서 AI 로 옮겨 갔다. 2026-11-25 에는 규칙 검사(scan)와 정책 팩을 걷어 내고
review 하나로 줄였다([decisions/0005](decisions/0005-review-only.md)).

## 왜 바꾸나

- **의무 대부분은 정적 규칙으로 가릴 수 없다.** 의무 지도(2026-10-15)에서 코드에 흔적이 남는 의무 795개 가운데
  Semgrep 조건만으로 가릴 수 있는 것은 11개(1.4%)였다. 606개(76%)는 코드의 뜻을 읽어야 하고, 178개(22%)는 여러
  파일·화면에 걸쳐 있다.
- **재현율을 막은 것은 판단력이 아니라 시야다.** 중간 평가(test F1 0.28)에서 놓친 양성 21건 가운데 15건은
  파일 하나만 보는 구조 때문이었다(생성형 AI 의 서버 파일, 나이를 다른 파일에서 받는 가입). AI 판정기를 켜면
  정밀도는 0.35 → 0.60 으로 올랐지만 재현율은 그대로였다.
- **계획서의 기술 일정과 맞는다.** 9~14주의 계획(코드 문맥 추출, AI 재검토, 독립 AI 검토, 근거 검증, 마스킹)은
  방향 A 에서 그대로 쓴다. 바뀌는 것은 대상 이슈다.
  계획서의 네 방식 비교 실험은 하지 않는다(2026-11-05, [decisions/0004](decisions/0004-no-accuracy-experiment.md)).

## 무엇이 그대로이고 무엇이 바뀌나

| 그대로 | 바뀐다 |
|---|---|
| 출력은 "확인할 것 + 근거 조문 + 확인 질문". 위반 판정이 아니다 | AI 가 판정의 중심이다(11/25 부터 AI 뿐이다) |
| 약한 근거로는 '코드에서 본 것'·'충족'을 주지 않는다 | 판정 단위가 파일·함수에서 의무 하나(서비스 전체)로 넓어졌다 |
| AI 의 '충족'은 코드에 글자 그대로 있는 줄을 인용해야 인정 | 인용이 여러 파일에 걸칠 수 있다(파일·줄·인용문). '없다'는 도구가 검색을 다시 돌려 확인한다 |
| 의무마다 조문 원문을 인용한다(의무 표·제재 표) | 의무는 의무 지도의 항목 id 다 |
| 프로필과 기록 재생은 모델 호출 0회, 외부 통신 0건 | 모델이 읽은 코드는 비밀값(키·토큰·개인키, 주민등록번호·카드 번호 모양)을 가린 뒤 보낸다 |

## 하지 않는 것 (이번 학기)

- 의무 수 늘리기 경쟁. 지도는 범위의 분모를 보이는 근거다. 묻는 의무는 220개(검토 후보)다.
- 자체 파서·데이터 흐름 엔진. tree-sitter·TypeScript 컴파일러로 엔진을 새로 짜는 일은 학기 뒤로 미룬다.
- 일반 보안 취약점 규칙(SQL 주입, XSS). Semgrep·CodeQL·플랫폼 AI 리뷰가 이미 무료로 한다.
- 법률 판단. 도구는 검토할 곳을 찾고 묻는다.

## 이미 있는 것과의 차이

국내 법을 코드에서 보는 도구는 이미 여럿 있다(LawLint, privacy-scan-kr, klaws, pipa-guard, launch-doctor-kr,
AnsimCode, vibecode-checker). "최초"를 주장하지 않는다. 우리가 보여 줄 차이는 넷이다.

1. AI 의 판단을 도구가 직접 대조한다. 인용은 코드에 글자 그대로 있어야 하고, '없다'는 도구가 다시 돌린 검색이
   같아야 받는다.
2. 상태가 일곱 갈래이고, 걸리는지가 사업자의 판단이면 '해당 여부부터'로 남겨 개발자에게 물을 질문이 된다.
3. 의무 지도와 조문 인용으로 "무엇을 보고 무엇을 보지 않는지"를 밝히고, 의무마다 법에 적힌 제재를 붙인다.
4. 끝까지 동작한다. 같은 검토가 로컬 CLI 와 공개 저장소를 분석하는 웹 서비스에서 돌고, AI 에 보내는 코드는 비밀값을
   가린 뒤 보내고, 가린 수와 읽은 파일 목록을 결과에 남긴다.

자세한 비교는 중간 보고서 2장에 있다([reports/](reports/)).
