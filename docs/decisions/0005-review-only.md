# 0005 제품은 review 하나다 — scan 과 정책 팩을 걷어 낸다

- 상태: 채택
- 날짜: 2026-11-25
- 대체하는 것: [0002](0002-semgrep-as-signal-backend.md)

## 배경

0002 는 Semgrep 을 "후보를 찾는 신호"로 낮추고 판정을 AI 와 인용 관문에 맡겼다. 그 뒤 판정의 길은 review(프로필 →
기능 파악 → 의무별 조사 → 반박 → 직접 대조)로 옮겨 갔고, scan 은 review 안에서 질문에 힌트를 주는 단계로만 남았다.
공개 저장소 41곳(11/13)에서 review 는 34곳에서 코드 줄 근거가 붙은 확인 항목을 냈고, scan 의 경고가 난 13곳은 모두
그 안에 있었다. scan 만 찾은 곳은 없었다(원자료 `~/.cache/policypack-eval/scan-eval-2026-11-24/`).

## 결정

scan 명령과 그것만 쓰던 것(정책 팩 kr-core 와 팩 문법·팩 시험, Semgrep 실행, 판정 엔진, 커밋 전 훅·Claude Code 훅·
GitLab 예제, scan 의 글·JSON·SARIF 보고서)을 지운다. review 안의 그 단계와 질문 힌트도 지운다. 제품은 "AI 가 코드를
읽어 걸릴 수 있는 법 의무를 근거와 함께 낸다" 하나다. 지운 것은 태그 `static-final` 에 남는다.

## 결과

- 모델 키 없이 경고를 내는 길이 없다. 키 없이 되는 것은 프로필(`profile`, `review --plan`)과 기록 재생(`replay`)이다.
- 커밋 전 훅·CI 의 SARIF 처럼 빠르고 모델을 부르지 않는 쓰임은 접는다.
- 설치가 가벼워졌다(실행 의존성 ruamel.yaml 하나). 시험이 10분 넘게 걸리던 것이 몇 초다.
- 의무 표의 `krcore` 칸(옛 팩이 다루던 의무 8개)은 묻는 의무를 정하는 데 그대로 쓴다(220개를 바꾸지 않으려고).
